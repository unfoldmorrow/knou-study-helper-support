KNOU Study Helper 개인정보 처리방침

시행일: 2026-09-07
개발자: jcpark-allthings

KNOU Study Helper(이하 “확장 프로그램”)는 U-KNOU와 KNOU LMS에서 자동 재생 보조 및 학습노트 저장 기능을 제공하는 Chrome 확장 프로그램입니다.

처리하는 정보와 목적

확장 프로그램은 지원 강의 페이지의 주소, 강의 제목·과목명, 화면에 표시된 학습 내용, 재생 상태·진행 정보와 사용자가 고른 설정을 기능 수행을 위해 브라우저 안에서 처리합니다. 설정은 Chrome 확장 저장소에 저장되며, 일시적인 탭·강의 상태는 현재 브라우저 세션에서만 관리됩니다.

사용자가 직접 저장을 요청하거나 자동 저장을 선택한 경우, 학습노트 또는 MP3 파일은 사용자의 Chrome 기본 다운로드 위치에 저장됩니다.

전송·공유·광고

확장 프로그램은 강의 내용, 로그인 정보, 쿠키, 학습노트 내용 및 설정을 개발자 또는 제3자 서버로 전송·판매·광고 목적으로 이용·공유하지 않습니다. 학습 내용의 읽기와 학습노트 PDF/HWPX/TXT 생성은 확장 프로그램에 포함된 코드로 브라우저 안에서 처리됩니다.

사용자 데이터는 위 단일 목적에 필요한 범위에서만 사용하며, 맞춤형 광고·리타기팅 광고에 사용하거나 사람의 열람을 허용하지 않습니다.

권한 사용

확장 프로그램은 U-KNOU와 KNOU LMS의 강의 페이지 및 각 강의에 포함된 동영상 재생 페이지에서만 페이지 접근 권한을 사용합니다. downloads는 학습노트·MP3 저장에, storage는 설정 보관에, notifications는 오류·완료 알림에 사용합니다. tabs, windows, webNavigation은 현재 강의 상태 확인, 알림 클릭 시 강의 창 표시 및 페이지 이동 감지에 사용합니다.

사용자의 선택

사용자는 Chrome 확장 프로그램 관리 화면에서 확장 프로그램을 사용 중지하거나 제거할 수 있습니다. 제거하면 확장 프로그램이 저장한 설정은 삭제될 수 있습니다. 이미 다운로드한 파일은 사용자의 다운로드 폴더에 남으므로 필요하면 직접 삭제해야 합니다.

외부 서비스

학교 사이트와 Chrome 브라우저는 각각의 개인정보 처리방침에 따라 정보를 처리합니다. 이 개인정보 처리방침 페이지는 GitHub Pages에서 제공되며, 페이지 방문에 관한 처리는 GitHub의 개인정보 처리방침이 적용됩니다.

방침 변경 및 문의

기능 또는 정보 처리 방식이 바뀌면 이 방침과 Chrome 웹스토어의 개인정보 공개를 함께 갱신합니다. 문의나 지원 요청은 지원 페이지에 남겨 주세요. 비밀번호, 인증 쿠키, 전체 강의 자료 등 민감한 정보는 올리지 마세요.
