방송대 학습도우미 - KNOU Study Helper 개인정보 처리방침

시행일: 2026-09-07
최종 수정: 2026-10-07
개발자: unfoldmorrow
문의: https://github.com/unfoldmorrow/knou-study-helper-support/issues

방송대 학습도우미 - KNOU Study Helper(이하 “확장 프로그램”)는 한국방송통신대학교(KNOU, 방송대·방통대) U-KNOU와 KNOU LMS에서 자동 재생 보조 및 학습노트 저장 기능을 제공하는 비공식 Chrome 확장 프로그램입니다. 이 방침은 확장 프로그램이 어떤 정보를 기능 수행을 위해 처리하는지 설명합니다.

처리하는 정보와 목적

확장 프로그램은 다음 정보를 브라우저 안에서만 처리합니다.

  • 사용자가 연 지원 강의 페이지의 주소, 강의 제목·과목명, 화면에 표시된 학습 내용, 재생 상태 및 강의 진행 정보: 자동 재생 보조, 재생 상태 표시, 사용자가 요청한 학습노트 생성에 사용합니다.
  • 사용자가 고른 설정(확장 사용 여부, 이어보기, 재생 속도, 다음 강의 이동 기준, 학습노트 저장 방식·형식, MP3 파일명 정리 설정 등): 다음 사용 시에도 선택을 적용하기 위해 Chrome의 확장 저장소에 저장합니다.
  • 일시적인 탭·강의 상태: 현재 브라우저 세션에서 오류·완료 상태와 강의 전환을 관리하기 위해 처리하며, 브라우저 세션이 끝나면 제거될 수 있습니다.
  • 학습노트 저장 확인 정보: 중복 저장을 확인하기 위해 과목·강의 제목, 파일명, 내용 해시와 저장 결과를 기기의 Chrome 확장 저장소에 보관합니다. 학습노트 본문을 개발자 서버로 전송하지 않습니다.
  • 사용자가 요청한 강의자료 조회: 현재 로그인 상태로 학교 게시판의 처음 5페이지까지 조회하고 게시물 제목·첨부파일 이름·다운로드 주소를 읽습니다. 첨부파일 다운로드 대기열과 진행 상태는 브라우저 세션 저장소에 일시 보관되며 브라우저 세션이 끝나면 삭제됩니다. 계정 비밀번호나 인증 쿠키를 별도로 수집·저장하지 않습니다.

학습노트 또는 MP3 파일은 사용자의 요청이나 사용자가 선택한 자동 저장 설정에 따라 사용자의 Chrome 기본 다운로드 위치에 저장됩니다.
강의자료 첨부파일은 사용자가 전체 또는 선택 다운로드를 누르면 기본 다운로드 폴더 아래 과목별 폴더에 저장됩니다.

정보의 전송·공유·보관

확장 프로그램은 위 정보, 로그인 정보, 쿠키, 학습노트 내용을 개발자 서버 또는 제3자 서버로 전송·판매·광고 목적으로 이용·공유하지 않습니다. 학습 내용의 읽기와 학습노트 HWP/HWPX/PDF/TXT 생성은 확장 프로그램에 포함된 코드로 브라우저 안에서 처리됩니다. 강의자료 조회와 파일 다운로드에는 사용자가 이용하는 학교 서버로의 요청이 필요하며 현재 로그인 세션을 사용합니다.

확장 프로그램이 저장하는 설정은 사용자의 Chrome 확장 저장소에 보관됩니다. 내려받은 학습노트와 MP3 파일의 보관·삭제는 사용자가 자신의 기기와 Chrome 다운로드 설정에서 관리합니다.

학교 사이트, Chrome 브라우저, 또는 사용자가 방문하는 다른 서비스가 독자적으로 처리하는 정보에는 각각의 개인정보 처리방침이 적용됩니다.

제한적 사용

확장 프로그램에서 처리하는 사용자 데이터는 위에서 설명한 단일 목적의 기능을 제공하는 데만 사용하며, Chrome 웹스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

권한 사용

확장 프로그램은 U-KNOU와 KNOU LMS의 학습목록·강의·강의자료 페이지 및 각 강의에 포함된 동영상 재생 페이지에서 페이지 접근 권한을 사용합니다. downloads는 학습노트·MP3·강의자료 첨부파일 저장에, storage는 설정·학습노트 저장 확인 정보와 세션 다운로드 상태 보관에, notifications는 오류·완료 알림에, tabs·webNavigation은 현재 강의 상태 확인과 알림 클릭 시 강의 창 표시 및 페이지 이동 감지에 사용합니다. alarms는 진단 응답 확인과 U-KNOU 재생 감시에 사용합니다. HWP·HWPX 학습노트는 브라우저 안에서 직접 생성합니다.

사용자가 ‘개발자에게 진단 로그 보내기’를 선택하면 접수 페이지의 입력칸에 진단 로그가 첨부됩니다. 사용자가 내용을 확인하고 전송해야 접수되며 확장이 자동으로 접수하지 않습니다.

진단로그

사용자가 진단로그를 켜면 오류와 재생 상태를 기기에 기록하며 직접 내보내거나 삭제할 수 있습니다. Chrome을 새로 시작하거나 마지막 창을 닫을 때, 확장 설치/업데이트 때 기록을 OFF로 바꿉니다. 팝업을 열고 닫아도 기록 설정은 유지합니다. 기존 로그는 OFF 전환 시 자동 삭제하지 않습니다. 이 버전은 debugger 권한과 포커스 에뮬레이션을 사용하지 않습니다.

사용자의 선택

사용자는 Chrome 확장 프로그램 관리 화면에서 확장 프로그램을 사용 중지하거나 제거할 수 있습니다. 제거하면 확장 프로그램이 저장한 Chrome 확장 저장소의 설정은 삭제될 수 있습니다. 이미 다운로드한 파일은 사용자의 다운로드 폴더에 남아 있으므로 필요하면 직접 삭제해야 합니다.

방침 변경

기능 또는 정보 처리 방식이 바뀌면 이 방침과 Chrome 웹스토어의 개인정보 공개를 함께 갱신합니다. 중요한 변경은 확장 프로그램 업데이트 전 또는 적용 전에 명확히 알립니다.
